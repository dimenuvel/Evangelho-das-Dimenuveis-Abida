# ABIDA — O JOGO


https://github.com/dimenuvel/Evangelho-das-Dimenuveis-Abida/releases/tag/v1.0

Um jogo estilo **Breakout** inspirado em **O Evangelho das Dimenúveis**.

Guie a bola de boliche luminosa através dos **Dez Giros da Espiral**, atravessando as Dimenúveis enquanto mantém o **Abidar** — presença, reconhecimento e fluxo.

> **Não destrua a Dimenúvel. Reconheça-a. Atravesse-a. Retorne ao centro.**

## Elementos

- 🌀 A Espiral
- 🎳 Boliche cósmico
- 🧶 O Tapete
- 🕊️ Abidar
- 🔥💨💧🌍 Os Quatro Elementos
- 🌀 IEOUA
- 👤 O Cara
- 👁️ Os Vazios
- **Os Dez Giros**
- **As Sete Dimenúveis**

O jogo funciona offline e foi desenvolvido para celulares Android.

# Instalação do APK

O APK é distribuído fora da Google Play.

### 1. Baixe o APK

Baixe o arquivo `.apk` disponibilizado pelo GitHub Actions ou pela release do projeto.

### 2. Abra o APK

Localize o arquivo usando **Arquivos/Files** ou o navegador e toque nele.

### 3. Permita a instalação

Se o Android informar que a instalação dessa fonte não é permitida:

**Configurações → Apps → Acesso especial a apps → Instalar apps desconhecidos**

Selecione o aplicativo que está abrindo o APK e ative:

**Permitir desta fonte**

Depois volte ao APK e toque nele novamente.

### 4. Instale

Toque em:

**Instalar**

Quando terminar, abra:

**Abida - O Jogo**

## Se aparecer "App não instalado"

Tente:

1. Desinstalar uma versão anterior do ABIDA se houver.
2. Baixar o APK novamente.
3. Verificar se há espaço suficiente no armazenamento.
4. Confirmar que você está instalando o arquivo **`.apk`**, e não um ZIP ou o código-fonte do GitHub.
5. Se o Android/Play Protect bloquear um APK não verificado, leia o aviso antes de prosseguir.

**Nota para builds de teste:** o APK deve ser gerado como `assembleDebug`, pois o Android assina automaticamente o debug APK com a chave de debug.
