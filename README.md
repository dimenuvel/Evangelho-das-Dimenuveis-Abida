# 🌀 The Sacred Rug Abides

> *"Sometimes you eat the bar, and sometimes, well... the bar eats you."*

**The Sacred Rug Abides** is a cosmic, Dudeist-inspired arcade game built with React, HTML5 Canvas, Tailwind CSS, and Web Audio API. Combining classic brick-breaking mechanics, sacred bowling pins, elemental power-ups, vowel harmony sequences (`I-E-O-U-A`), and meditative lore, it invites players on a spiritual journey across 10 distinct Turns to restore balance to the universe.

---

## 🌟 Key Features

- **10 Unique Cosmic Turns**:
  1. **Turn 1**: *The Cosmic Bowling Alley* — Classic brick layouts & bowling pin formations.
  2. **Turn 2**: *The Rug That Tied The Room Together* — Sacred rug weaves & high-value strikes.
  3. **Turn 3**: *Earth Element* — Dense emerald barriers & ground shield defense.
  4. **Turn 4**: *Water Element* — Fluid azure currents & paddle expansion waves.
  5. **Turn 5**: *Fire Element* — Fiery speed boosts & high-velocity action.
  6. **Turn 6**: *Air Element* — Weightless gusts & unpredictable wind physics.
  7. **Turn 7**: *The Void (Void/Illusion)* — Inverted control illusions & optical tricks.
  8. **Turn 8**: *The Sacred Vowels (I-E-O-U-A)* — Hit blocks in harmonic order to unleash cosmic bonuses.
  9. **Turn 9**: *The Dude's Mind* — Multi-orb chaos and deep state flow.
  10. **Turn X**: *Return to the Center* — Radial orb challenge where you hit the Golden Core to transcend.

- **The Abide Meter & Abide Mode**:
  - Keep your cool with smooth paddle control to fill the **Abide Meter**.
  - When full, unleash **Abide Mode** for 12 seconds of invulnerability, enlarged rug paddle, double scoring, and golden trailing visual effects.

- **Sacred Vowel Harmony (`I-E-O-U-A`)**:
  - Strike vowel blocks in exact sequence (`I -> E -> O -> U -> A`) for massive bonus points and cosmic audio resonance.

- **Dialogue & Cutscenes**:
  - Spiritual discussions between **The Dude**, **The Disciple**, and **The Stranger** (`🌀`) before key Turns.

- **Sound Lab & Meditation Mode**:
  - **Sound Lab**: Experiment with synthesizers, harmonic frequencies, ambient binaural drones, and sound effects.
  - **Meditate Mode**: Interactive breath-pacing and ambient soundscapes to unwind between runs.

- **Bilingual Support & Themes**:
  - Full support for **English** and **Portuguese (PT-BR)**.
  - **Day (Serene Linen)** & **Night (Obsidian Void)** visual themes.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Custom Fonts (Cinzel, Inter)
- **Game Engine**: HTML5 Canvas with custom 60fps Physics & Particle System
- **Audio Engine**: Web Audio API (Synthesizers, Ambient Drones, Custom Sound Effects)
- **State & Context**: React Context API (`ThemeContext`, `LanguageContext`)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/sacred-rug-abides.git
   cd sacred-rug-abides
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.

---

## 🕹️ Controls

- **Mouse / Touch**: Move the paddle (*The Rug*) left and right.
- **Click / Tap / Spacebar**: Release or launch the cosmic orb.
- **Smooth Play Style**: Avoid chaotic, frantic movements to preserve your Abide Meter balance.
